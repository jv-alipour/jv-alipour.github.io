Software

Open-source tools for empirical research. All code is on GitHub.

  • PullRegiostat Python client for the Regionalstatistik API, Germany's official regional statistics portal, operated by the Federal and State Statistical Offices.
  • samefile Stata wrapper for a Python routine that checks whether two files are identical based on their hash values.
  • grconst Stata module to check whether a variable is constant within groups, flag conflicts, and fill in missing values.
  • adoactive Stata module to identify and return a list of user-written Stata commands called in a do-file.
  • pushmess Stata module for sending push notifications using the PushNotifier app.
